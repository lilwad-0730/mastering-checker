獨立音樂人發行規格建議小錦囊：

  • 44.1 kHz vs 48 kHz： Spotify 與 Apple Music 支援 44.1kHz 與 48kHz 無損上架；若有配樂配影音需求，導出 48kHz 能避免重採樣 (Resampling) 造成的失真。
  • 24-bit PCM： 母帶交付絕佳選擇，位元深度決定動態範圍 (24-bit 具備 144dB 動態)，遠優於 16-bit (96dB)。
  • 32-bit Float： 適用於混音與 DAW 中間檔，但上架發行商 (DistroKid/Tunecore) 通常要求轉為 24-bit 或 16-bit WAV。

數位發行商 (DistroKid / Tunecore / CD Baby)
  • 副檔名： 推薦 .wav 或 .flac
  • 編碼： Uncompressed PCM, 24-bit / 44.1kHz 或 48kHz

Apple Digital Masters 高品質認證
  • 規格： 24-bit / 96kHz 或 48kHz 24-bit WAV
  • Peak 規範： True Peak 嚴格限制於 -1.0 dBTP 以下，絕不可有 Inter-sample Clipping
